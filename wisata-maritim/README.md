# Indonesia Maritime Journey

Website wisata maritim Indonesia (HTML, CSS, dan JavaScript murni, tanpa build tool).

## Struktur
- `index.html` : kerangka halaman
- `css/style.css` : seluruh gaya tampilan
- `js/data.js` : data destinasi (`RAW`) dan daftar wilayah (`WIL`)
- `js/app.js` : logika pencarian, filter, peta rute, dan tampilan

## Cara menjalankan
Buka `index.html` di browser, atau di VS Code pakai ekstensi **Live Server**
(klik kanan `index.html` > Open with Live Server).

Catatan: harga adalah estimasi dan perlu diverifikasi ke pengelola.
